# AutoKey Web · 连按控制台

在浏览器中控制 macOS 自动重复按键。支持数字键 1–9、间隔调节、开始／暂停／停止和实时计数；每次按键前尝试激活 iPhone Mirroring（iPhone 镜像）。

## 功能

- **按键选择**：支持数字键 1–9，默认按键为 `2`。
- **可调间隔**：范围为 0.1–3600 秒，默认 3 秒，可在运行中调整。实际按键周期还包含应用激活和按键事件耗时。
- **运行控制**：开始、暂停／继续、停止，以及手动按一次。
- **统计**：显示本次按键次数、累计次数和本次运行时长。统计保存在内存中，退出程序后重置；运行时长包含暂停时间。
- **两种界面**：主控制台和紧凑迷你面板。

## 环境要求

- macOS，Python 3.9 或更高版本。
- 首次安装依赖时需要联网。
- 在「系统设置 → 隐私与安全性 → 辅助功能」中，为启动程序的终端／Python 运行环境授予控制权限。
- 如需控制 iPhone 镜像，请先完成镜像连接，并使用支持该功能的 macOS 与 iPhone。

程序通过 macOS 原生键盘事件工作；网页需要配合本机 Python 服务运行。

## 快速启动

1. 下载仓库：点击 **Code → Download ZIP**，然后解压；也可以使用 Git：

   ```bash
   git clone https://github.com/lindixu6-hash/auto-key-web.git
   ```

2. 在项目文件夹中双击 `start.command`。
3. 启动脚本会创建 `.venv`、安装所需依赖，并自动打开主控制台：

   <http://127.0.0.1:8866/>

如果下载后的启动脚本无法执行，可在项目目录的终端中运行：

```bash
bash start.command
```

也可以手动安装和启动，在项目目录执行：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python auto_key_web.py
```

## 使用方法

1. 打开并连接 iPhone Mirroring。
2. 在主控制台选择按键，并设置间隔。
3. 点击「开始」重复按键；点击「暂停」暂时停下，再点一次继续。
4. 点击「停止」结束本次连按；重新开始会清零本次计数。
5. 需要单次操作时，点击「手动按一次」。

主界面中点击数字按钮仅选择按键；迷你面板中点击数字按钮会立即按一次，并将该数字设为后续连按使用的按键。

迷你面板地址：<http://127.0.0.1:8866/mini>

快捷键在网页获得焦点时生效：

- **1–9**：主界面切换按键；迷你面板立即按一次。
- **空格**：运行中暂停／继续。

退出服务：在启动程序的终端中按 `Ctrl+C`。

## 常见问题

**页面打开了，但目标应用没有响应**

检查辅助功能权限，并确认 iPhone 镜像已连接。按键发送到当时的前台应用；如果镜像激活失败，事件可能发送给其他前台应用。页面中的计数表示程序已发送事件，不代表目标应用已完成操作。

**提示 Quartz 不可用**

使用 `start.command` 安装依赖，或在项目目录重新执行：

```bash
.venv/bin/python -m pip install -r requirements.txt
```

**提示端口已被占用**

默认端口为 `8866`。先检查是否已有控制台运行；如需同时运行另一份，可修改 `auto_key_web.py` 中的 `PORT`，再重新启动。

## 项目文件

| 文件 | 用途 |
| --- | --- |
| `auto_key_web.py` | macOS 按键事件、HTTP 接口、主界面与迷你面板 |
| `requirements.txt` | Quartz 与 Cocoa 的 Python 依赖 |
| `start.command` | 创建环境、安装依赖并启动 |
| `.gitignore` | 排除虚拟环境、缓存和本地日志 |

服务默认仅监听本机 `127.0.0.1`，无需账号或云端服务。
